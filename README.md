# data-analytics-app

This is a repository containing the constituting components of a data analytics system and web application.

The system is comprised of the following components:

- data-analytics-dash
- data-analytics-spark-app
- data-analytics-oauth-service
- data-analytics-data-service
- data-analytics-web-proxy
- data-analytics-ui

Each of the components has its own README.

The system is currently under development and not in active use.

A monorepo is used for the system in order to provide a clear image of the system as it exists as a whole.
